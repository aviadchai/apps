# CarScope — דוח רכב חינמי בישראל

אתר RTL בעברית: [האתר הפעיל ב-GitHub Pages](https://aviadchai.github.io/apps/carcheck/)

המערכת משתמשת ב-API של משרד התחבורה ב-[data.gov.il](https://data.gov.il), ולא ממציאה תוצאות כשאין מידע. בשירות GitHub Pages, הדפדפן מבצע קריאה ישירה ל-CKAN API. אם CORS נכשל, יש תמיכת JSONP שמפורטת גם בתיעוד הממשלתי. פריסת Vercel עתידית יכולה להשתמש גם בנתיב השרת `/api/vehicle`.

## מידע שמגיע מהמאגר

- רישוי, דגם, יצרן, שנתון, רמת גימור, תאריכים ומידע טכני.
- קילומטראז׳ בטסט **האחרון בלבד**, אם קיים במאגר.
- תאריכי העברות בעלות וסוגי הבעלות. הסיווגים "סוחר", "השכרה", "החכר" ואחרים מסומנים.
- אינדיקציית "מקוריות" מתוך מאגר היסטוריית הרכב (1), כשקיימת.

מקורות:

1. [רישוי רכב פרטי ומסחרי](https://data.gov.il/he/datasets/ministry_of_transport/private-and-commercial-vehicles/053cea08-09bc-40ec-8f7a-156f0677aff3).
2. [ק״מ ומקוריות — מאגר היסטוריית הרכב (1)](https://data.gov.il/he/datasets/ministry_of_transport/shinui_mivne/56063a99-8a3e-4ff4-912e-5966c0279bad).
3. [סוגי בעלות ותאריכים — מאגר היסטוריית הרכב (2)](https://data.gov.il/he/datasets/ministry_of_transport/shinui_mivne/bb2355dc-9ec7-4f06-9c3f-3344672171da).

## CarScope Insights — תוספות

- **מעקב ק״מ**: ניתן לשמור ידנית קריאות עם תאריך ומקור (טסט, מוסך, צילום, דיווח מוכר). כל חיפוש שומר גם את הקריאה העדכנית מהממשלה כפי שנצפתה באותו זמן. קריאות נשמרות ב-localStorage של אותו דפדפן בלבד. המערכת מזהה ירידות בק״מ, סתירות בתאריך אחיד וקצב עליה חריג.
- **בדיקת בעלויות**: הדגשת בעלויות לא פרטיות ו"דגל" להשכרה, החכרה, ליסינג ובעלות מוסדית גם בשדה "מקוריות", אם הנתונים נמצאים.
- **מחירונים**: קישורים רשמיים למחירון יד2, לאתר לוי יצחק ולמודעות רכב.
- **גרף מחיר הדגם**: כאשר משתמש מוסיף מחירים ממודעות/מחירונים לשני שנתונים לפחות, מוצג קו חציוני לפי שנתון. נשמר מקומית בלבד. הנתונים אינם מחירון רשמי, אינם ממוצע שוק מייצג, ואין הנחה שמחירי מודעות הם מחירי עסקאות.
- **גרף ק״מ**: מופיע רק כאשר קיימות לפחות שתי קריאות מתוארכות מותרות להשוואה.

## מגבלות ואמינות

מאגרי היסטוריית כלי הרכב הפרטיים מציגים בעיקר רכבים פעילים משנת 2017 והלאה; לרכב ישן ייתכן שלא יוחזר מידע היסטורי. משרד התחבורה **לא מפרסם בשירות הזה היסטוריית ק״מ לכל הטסטים**. השוואה כזו אפשרית רק על סמך מדידות נוספות שהמשתמש סיפק או שנשמרו בבדיקות שונות בעתיד. היעדר התרעה אינו אישור לקילומטראז׳ מקורי; התרעה אינה הוכחה לרמאות.

מספר רשומות הבעלות אינו בהכרח מספר היד הרשום ברישיון. אין במערכת כיום גישה אוטומטית מורשית לשווי פרטני במחירון לוי יצחק או יד2, לתאונות, שעבודים, בדיקות מכניות או היסטוריית טיפולים. אין למכור או להציג דוח זה כתחליף למסמכים רשמיים או לבדיקה פיזית במכון.

## קבצים

- `index.html` — ממשק וחיבור CKAN ישיר ל-GitHub Pages
- `insights.js` — ניתוח וגרפים, אחסון מקומי
- `insights.css` — עיצוב ההרחבות
- `api/vehicle.js` — backend אופציונלי עבור Vercel
- `tests/vehicle.test.js` — בדיקות יחידה
