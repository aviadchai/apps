# CarScope — בדיקת רכב לפי מספר רישוי

מערכת קוד פתוח בעברית (RTL), מותאמת לנייד, לבדיקת מידע על רכב מתוך מאגרי משרד התחבורה בישראל.

## מה עובד

- הזנת מספר רישוי ישראלי בן 7 או 8 ספרות.
- שאילתות בזמן אמת מהשרת לשלושת מאגרי data.gov.il:
  1. [כלי רכב פרטיים ומסחריים](https://data.gov.il/he/datasets/ministry_of_transport/private-and-commercial-vehicles/053cea08-09bc-40ec-8f7a-156f0677aff3).
  2. [היסטוריית רכב (1) – ק"מ בטסט האחרון](https://data.gov.il/he/datasets/ministry_of_transport/shinui_mivne/56063a99-8a3e-4ff4-912e-5966c0279bad).
  3. [היסטוריית רכב (2) – מועדי בעלויות וסוגיהן](https://data.gov.il/he/datasets/ministry_of_transport/shinui_mivne/bb2355dc-9ec7-4f06-9c3f-3344672171da).
- שקיפות לגבי תקלות במקורות ומידע חסר. מעולם לא מציגים נתוני דוגמה כנתוני אמת.
- כפתורים להעתקת סיכום ולהדפסת הדוח/שמירה כ-PDF מתוך הדפדפן.

## מגבלות חשובות

היסטוריית רכבים פרטיים נכללת בעיקר עבור רכבים פעילים משנת 2017 ואילך; רכב 2016 עשוי להופיע רק במאגר המפרט, בלי היסטוריית ק"מ ובעלויות.
נתון הק"מ הוא **הקריאה האחרונה שמופיעה במאגר**, ולא ציר זמן של כל הטסטים. מספר רשומות העברת הבעלות איננו מספר היד הרשום ברישיון. המאגר אינו כולל בדיקות מכניות, תביעות ביטוח, שעבודים או היסטוריית טיפולים.

## הרצה ופיתוח

נדרש Node.js 20 ומעלה:

\`\`\`bash
npm install
npx vercel dev
\`\`\`

פתח http://localhost:3000 והזן מספר רכב. ההרצה דרך Vercel Dev מפעילה גם את API Route שבנתיב api/vehicle.js.

בדיקות יחידה:

\`\`\`bash
npm test
\`\`\`

## פריסה

בחר ב-Vercel את המאגר \`aviadchai/apps\`, את Root Directory \`carcheck\`, ואת Framework Preset \`Other\`. אין צורך במפתח API. הקבצים \`index.html\` ו-\`api/vehicle.js\` מוכנים לפריסה.

## גישה למקורות

קריאות שרת מבוצעות מול \`https://data.gov.il/api/3/action/datastore_search\`, עם filter לפי \`mispar_rechev\`, timeout לכל מקור ושמירת Cache קצרה. אם כל המקורות אינם זמינים, הבקשה נכשלת בגלוי, במקום להמציא נתונים.

המערכת אינה אתר ממשלתי ואינה מחליפה בדיקת רכב מקצועית. שימוש במאגרים כפוף לתנאי המקור ולכללי הגנת הפרטיות.
