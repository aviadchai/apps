# CarScope — מערכת בדיקת רכב בעברית

**אתר:** https://aviadchai.github.io/apps/carcheck/

**קוד ה-API העצמאי:** [backend](./backend/)

## מה קיים עכשיו באתר

- ממשק בעברית (RTL), כחול־ממשלתי, ולוחית צהובה עם IL בשחור.
- קריאה ישירה של נתוני משרד התחבורה (data.gov.il) למפרט, לקריאת הטסט האחרונה, למקוריות ולרשומות בעלויות, כאשר זמינים.
- תוויות מידע i להסבר "החכר", "סוחר", "השכרה", "מקוריות", "טסט" ושדות רלוונטיים.
- הסרת כל האפשרויות להזנת קילומטראז׳ או מחיר באופן ידני.
- גרף קילומטראז׳ שמופיע רק כאשר קיימות לפחות שתי קריאות שניתן לייחס למקור.
- גרף מחירי הדגם שמתמלא רק ממודעות שנקלטו בהיתר ונשמרו בשרת; אין גרף מזויף או מחירון לא מורשה.
- הודעה גלויה כשהארכיון המרכזי אינו מחובר, או כשהמקור הממשלתי אינו מספק היסטוריה.
- תיעוד מקורות ומגבלות המידע, הבחנה בין "יד" לרישום אצל סוחר.

- ליד כל שדה מוצגים המאגר שממנו הגיע (עם קישור לשאילתה המדויקת) ומועד השליפה. שדה שאינו קיים במאגר מסומן "לא פורסם" או "השדה אינו קיים במאגר".
- אם עמודת מספר הרכב המתועדת נכשלת, הקוד קורא את מבנה המאגר (`limit=0`) ומנסה שוב פעם אחת עם העמודה האמיתית. כשל במקור אחד לא מפיל את הבדיקה.
- **אותות סיכון** מחושבים רק מנתונים שהתקבלו, וכל אות מציג את הנתון שהפעיל אותו: בעלות שהוחזקה פחות מ-3 חודשים, ק״מ מתחת ל-50% או מעל 150% מ-14,700 ק״מ לשנה (הלמ״ס), רישום על סוחר, טסט שפג או יפוג בתוך 60 יום, ריקולים פתוחים ורשומת ביטול.
- **מודעות:** אין גריפה (scraping) ואין שימוש ב-API לא מורשה. יש רק קישורי חיפוש ליד2 ול-Facebook Marketplace, ותיבת "הדבק מודעה" שמחלצת מחיר, ק״מ, יד, שנה ומיקום ומשווה אותם לנתוני הממשלה. העיבוד מתבצע בדפדפן בלבד.
- בדיקות: `npm test` בתיקייה `carcheck`, כולל fixture שמבוסס על 28845001.
- ה-backend (Worker/Vercel) עדיין מחזיר רק את 3 המאגרים המקוריים. כשהוא מוגדר, הדפדפן משלים את שאר המאגרים במקביל.

## API עצמאי — Cloudflare Worker + D1

התיקייה [backend](./backend/) מכילה API משלנו ומסד נתונים:

- GET \`/api/vehicle?plate=12345678\` — מידע ממשלתי, מקוריות, היסטוריה שנאגרה, התרעות.
- GET \`/api/prices?manufacturer=...&model=...\` — מחירי מודעות מורשות בלבד; נשאר ריק עד חיבור מקור מורשה.
- GET \`/api/health\` — סטטוס השירות.
- D1 שומר קריאות טסט עם תאריך, תאריך תצפית, מקור, והצלבות.
- משימה אוטומטית יומית מרעננת עד 50 מספרי רכב שנצפו בעבר (MVP; לא כל כלי הרכב בישראל).

**סטטוס:** קוד השרת נמצא ב-GitHub ונבדק במבדק מבוקר עם תשובות מדומות של משרד התחבורה, אך עדיין **אינו פרוס** לחשבון Cloudflare ולא מחובר למסד נתונים חי. אתר GitHub Pages משתמש בינתיים בקריאות ישירות ל-data.gov.il. להפעלה מלאה יש להריץ יצירת D1 ומיגרציות, לפרוס Worker, ואז לעדכן את \`api-config.js\` בכתובת המאומתת.

## מגבלות המחקר

במאגר הציבורי \`56063a99-8a3e-4ff4-912e-5966c0279bad\` יש שדה \`kilometer_test_aharon\`, כלומר הקריאה של **הטסט האחרון בלבד**. אין ב־API הזה כל קריאות הטסט הקודמות. ארכיון שנקים ייצור רצף רק מזמן תחילת המעקב; כדי לכסות שנים קודמות נדרש מקור ארכיוני אמיתי או הסכם גישה מסחרי.

Carzone מציגה טסטים והיסטוריית מודעות, אך אין במערכת גישה מורשית למאגר הפנימי שלה. אין לשכפל מאגרים מסחריים ללא היתר.

משרד התחבורה: https://data.gov.il/he/datasets/ministry_of_transport/shinui_mivne  
קארזון: https://www.carzone.co.il/car-report

הנתונים אינם משמשים חלופה לדוח עבר ביטוחי, לבדיקת רכב מקצועית או למסמכי המוכר. CarScope הוא שירות עצמאי, ולא אתר ממשלתי.
