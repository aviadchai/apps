## 🎵 Μελωδία — לומדים יוונית משירים (`greek-songs.html`)

לימוד יוונית מודרנית דרך מילות שירים: קריאה עם תרגום והשמעה (Web Speech, `el-GR`),
לחיצה על כל מילה לפירוק דקדוקי, תרגול ביטויים בשיטת ריווח (Pimsleur/SRS), והשלמת מילים.
ההתקדמות נשמרת ב-localStorage.

### איך מוסיפים שיר

יש שלוש דרכים, לפי מה שנוח:

1. **ידנית ב-`greek-songs.json`** (מומלץ, בלי מפתח): הקובץ הוא מערך של אובייקטי שיר. העתיקו את
   שיר הדוגמה, החליפו את התוכן, ושמרו. סכמה:
   ```
   { id, title (יוונית), titleHe (עברית), artist, youtubeUrl,
     lines: [ { gr, translit, translitHe, he,
                words: [ { gr, lemma, pos, he, note } ] } ],
     keyPhrases: [ { gr, he, note } ] }
   ```
   כל שדה `id` חייב להיות ייחודי. אין צורך לגעת בקוד — האפליקציה טוענת את הקובץ אוטומטית.
2. **הדבקת JSON מוכן** — מסך "הוספת שיר" ‹ "הדבקת שיר מוכן (JSON)" (נשמר במכשיר, localStorage).
3. **יצירה אוטומטית עם AI** — מסך "הוספת שיר": מדביקים מילים ביוונית + מפתח Anthropic API
   (`console.anthropic.com` ‹ Billing ‹ API Keys). הבקשה נשלחת ישירות מהדפדפן ל-Claude
   (`claude-opus-5`), המפתח נשמר רק במכשיר. אין צורך במפתח לשתי הדרכים הראשונות.

> אין להטמיע מילות שיר מוגנות בזכויות יוצרים במלואן ב-`greek-songs.json` שב-repo הציבורי.
> הדרך עם המפתח בונה את השיר המלא באופן פרטי בדפדפן שלכם.

## 📅 לוח שהות משותף (`custody.html`)

לוח זמני משמורת לשני הורים פרודים — תצוגת אג'נדה יומית, החלפות בשעות מדויקות, כלל חוזר
עם override נקודתי, וחישוב שעות/אחוזים לכל הורה. הנתונים ב-Firebase Firestore (זמן אמת):
כל לוח מזוהה ב-`?s=<id>` בכתובת — משתפים את **אותו קישור** עם ההורה השני, וזה הכל
(אין התחברות). כפתור 🔗 מעתיק את הקישור.
